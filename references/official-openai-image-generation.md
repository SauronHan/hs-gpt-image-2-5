# 官方 OpenAI GPT-Image-2.5 图像能力记录

记录日期：2026年最新。此文档记录 OpenAI 官方发布的 GPT-Image-2.5 核心能力边界与提示词工程规范。

## 一、 模型代际与版本特性

OpenAI GPT-Image-2.5 是相比于 Images 2.0 的全面升级版，聚焦于**一致性、微创编辑精度与生成速度**：

- **生成速度倍增**：端到端延迟降低最高 50%，支持极速迭代。
- **高保真光影与细节质感**：更自然的光照衰减、丰富的皮肤纹理与真实材质物理反射。
- **卓越的主体参考图保持（Identity Preservation）**：跨场景、跨构图、跨打光条件下，人物五官骨相、发型、商品物理形态特征的锁定能力显著超越前代。
- **精准的局部微创编辑（Precise Inpainting & Editing）**：超强的自然语言指令遵循度，可精准变更单一元素（如替换背景、修改局部颜色或增加道具），绝不破坏未指定的其余画面区域。
- **官方模型分支**：
  - `gpt-image-2.5`（或旗舰款 `gpt-image-2.5-sunburst`）：主打极致画质、复杂分镜构图与毫米级微创编辑精度（专业影视与设计首选）。
  - `gpt-image-2.5-flare`：主打极低延迟与快速生成，适合高频创意探索与社交媒体物料。

## 二、 核心参数与格式规范

| 参数项 | 支持规格 | 生产级实战规范 |
| :--- | :--- | :--- |
| **model** | `gpt-image-2.5`（默认）、`gpt-image-2.5-sunburst`、`gpt-image-2.5-flare`、`gpt-image-2` | 明确指定版本，专业影视镜头推荐 `gpt-image-2.5` |
| **task_type** | `GENERATE`（文生图）、`EDIT`（参考图微创编辑） | 无像素继承时选 `GENERATE`；需锁定主体特征或局部修改时选 `EDIT` |
| **quality** | `low` / `medium` / `high` / `auto` | 默认为 `auto`，精细分镜制作推荐显式指定 `high` |
| **size** | 长宽均为 16 的倍数，最长边 $\le 3840$，总像素 $65.5万 \sim 829.4万$ | 常见标准：`1024x1024` (1:1)、`1792x1024` (16:9 宽银幕)、`1024x1792` (9:16 竖屏) |
| **output_format** | `png` / `webp` / `jpeg` | 无损精修推荐 `png`，高效存储推荐 `webp` |
| **background** | `opaque`（不透明）/ `transparent`（透明背景） | 道具与角色母版抠像推荐 `transparent`，完整分镜选择 `opaque` |

## 三、 官方提示词工程黄金铁律

1. **正向具象描述优先于负向排斥**：
   - 官方推荐：“清晨柔和侧逆光照亮人物面部轮廓，背景为虚焦的湿润绿植”，优于“不要暗光，不要噪点”。
2. **多图特征分离与显式声明**：
   - 引用多张参考图时，必须为每张图赋予单一明确职责（如：`参考图1锁定面部骨相，参考图2锁定风衣材质与版型，参考图3锁定镜头构图`），防止属性串扰。
3. **微创编辑的边界守恒（一次只改一处）**：
   - 明确声明【唯一变更项 (CHANGE)】与【绝对保持项 (PRESERVE EXACTLY)】，利用 GPT-Image-2.5 的注意力锁定能力实现外科手术式微创修改。

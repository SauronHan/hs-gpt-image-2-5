# GPT-Image-2.5 参考图与微创编辑约束规范

在 OpenAI GPT-Image-2.5 中，模型的视觉理解和指令遵循能力大幅提升。为了充分发挥其在「主体一致性保持」与「局部精准微创编辑」上的强大优势，必须遵循以下工业级约束准则。

---

## 一、 参考图是真实输入，不是文字占位符

每一张在任务卡中被引用的参考图，必须满足以下结构化声明：

| 字段 | 必填含义 |
| :--- | :--- |
| `path_or_status` | 实际本地文件路径，或系统中已上传可访问的资源 URL |
| `priority` | 多图输入时的约束优先级（数字越小越优先，1 为最高权重基底） |
| `lock` | **绝对锁定继承项**：明确指定从该图中提取什么特征（如五官相貌、服装版型、道具几何结构或光影影调） |
| `ignore` | **显式排除项**：明确声明忽略图中的哪些无关信息（如中性背景、旧姿态、临时光照或杂乱反光） |
| `role` | 参考图角色定位（如 `FACE_IDENTITY_ANCHOR` 人脸锚点、`OUTFIT_REFERENCE` 服装基准、`SKETCH_LAYOUT` 草图构图） |

> **铁律**：缺少真实图片时，任务降级为纯文本 `GENERATE`；严禁编造未上传的虚假路径。

---

## 二、 多参考图解耦原则（防特征串扰）

当需要结合多张图片生成新画面时，GPT-Image-2.5 支持多图上下文。但必须在提示词中执行**特征解耦隔离**：
- **专图专用**：严禁让同一张图既充当人脸基准又充当姿态和背景基准；
- **分工明确**：
  - `参考图1`：专注锁定人物核心面相 DNA，显式声明忽略其背景与光线；
  - `参考图2`：专注锁定指定服装面料与版型，忽略该模特的长相与身材；
  - `参考图3（或手绘草图）`：专注锁定摄影机机位、人物空间站位与构图留白。

---

## 三、 微创编辑四大铁律 (LIRA-level Editing Discipline)

1. **编辑即后处理（Post-processing, Not Re-generation）**：
   - 编辑是在既有像素上的微创外科手术，不是推倒重建；严禁因为细微修改导致整个背景或未指定的人脸五官重绘。
2. **一次只改一处（One Change at a Time）**：
   - 严禁单次请求同时修改发型、服装颜色、天气和背景道具；每次只修改一个独立变量，步步迭代。
3. **最小改动 + 穷举保留（Minimal Change & Exhaustive Preserve）**：
   - 结构化编辑提示词必须显式拆分为三块：
     - `【唯一修改项 (CHANGE)】`：极为精细地描述唯一允许变更的具体部位与质感；
     - `【绝对保持项 (PRESERVE EXACTLY)】`：穷举列出五官、发丝、服装接缝、主光源角度与景深虚焦等绝对不变项；
     - `【绝对排除项 (EXCLUDE)】`：严禁波及未指定的邻近区域。
4. **正向具象描述优先于负向排斥**：
   - 描述“光滑干净、微带皮脂光泽的平整皮肤”，远优于描述“不要痘痘、不要斑点、不要皱纹”。

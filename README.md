# hs-gpt-image-2-5

> [English](README_EN.md) | **中文**

OpenAI GPT-Image-2.5 工业级图像生成与微创编辑提示词编译器（Skill）。

专为高质量电影分镜、角色概念设计与视觉资产打造。深度适配 OpenAI 最新一代 **GPT-Image-2.5** 图像底模，严格落实**多参考图特征解耦**、**结构化微创编辑（一次只改一处/穷举保留）**、**高质感光影与物理材质刻画**及**标准任务卡编译**。

---

## 🌟 核心特性

- **原生适配 GPT-Image-2.5**：充分利用 2.5 代模型更强的**人脸/主体身份锁定（Identity Preservation）**、**光影真实感**与**高精度指令遵循**能力。
- **三大多模态创作模式**：
  - **文生图 (GENERATE)**：运用电影级摄影机参数（焦段、景深、构图）、高反差光影系统（chiaroscuro）与具象材质语言驱动高质感画面。
  - **多参考图解耦 (MULTI-REFERENCE GENERATE)**：支持人脸相貌、服装款式与场景草图分离输入，严密隔离特征，防止串扰混淆。
  - **微创局部编辑 (EDIT)**：严格贯彻“一次只改一处”与“最小改动+穷举保留”，实现毫米级外科手术式微调，绝不破坏非指定区域。
- **纯粹、轻量、即插即用**：专注于生成结构化、高保真提示词与任务卡，零外部环境负担。

## 🛠️ 前置环境准备 (Prerequisites)

本 Skill 本质是一个纯粹的 **AI 图像提示词编译与操作卡编排引擎**：
- **零外部环境依赖**：无需在本地配置 Python 库、无 GPU 要求、无特定 SDK 或 API 密钥要求。
- **即插即用**：只要您的客户端（如 Claude Desktop、Antigravity、Cursor 或任意兼容 Agent Skills 体系的 AI 对话环境）支持大语言模型，即可直接运行本 Skill。
- **自由使用**：本 Skill 的核心产出物为规范的提示词与操作卡。生成后，您可以自由复制到 ChatGPT 网页端、OpenAI API 平台或任何支持 GPT-Image-2.5 的第三方工具中使用。

## 🚀 安装与使用

### 安装 Skill
将本目录克隆或复制到您的 AI Agent 技能目录中：

```bash
git clone https://github.com/your-username/hs-gpt-image-2-5.git
```

### 使用方式
直接在 AI 聊天对话中发送您的画面创意构思、角色设定或微创修改需求：
> “帮我生成一个科幻电影分镜：暴雨暗夜中的地下黑市义体医生，35mm 变形宽银幕电影镜头，高反差冷色调 chiaroscuro 光影，生成 16:9 任务卡。”  
> “这是主角的面部母版 `face.png`，请结合这张复古皮夹克参考图 `jacket.png`，生成他在黄昏机库倚靠战机的画面。”  
> “基于已有的原图 `character.png` 进行微创编辑：只在主角右侧额角添加一条新鲜擦伤划痕，其余五官面容、服装与背景完全保持不变。”

## 📂 处理输出结果与范例 (Outputs & Examples)

执行本 Skill 后，Agent 会交付一份完整的 **工业级操作卡 Markdown 文档**。以下为两类典型输出范例：

### 范例 1：文生图标准任务卡 (GENERATE)

```markdown
## 图像任务：SHOT_001_CYBER_CLINIC

- model: gpt-image-2.5
- task_type: GENERATE
- purpose: 电影概念分镜主画面
- quality: high
- size: 1792x1024
- background: opaque
- output_format: png
- reference_images: 无

### 结构化提示词 (Prompt)

【画面类型与主旨】
为赛博朋克科幻电影生成一张冷峻逼真的分镜概念画面。一位年约五十岁的地下义体医生在杂乱冰冷的诊所手术台前，专注于检修一支机械义肢手臂。

【主体与细节】
- 核心主体：医生面容消瘦硬朗，眉弓突出，灰白短发微汗贴在额前，鼻梁上架着带微距辅助镜片的钛合金复古放大镜。
- 服装与材质：内穿深墨绿色高领阻燃内衬，外披一件深灰色重磅橡胶质感防护围裙，围裙表面有微量机油污渍与使用磨损反光。
- 动态状态：双手戴着薄款黑色丁腈手套，右手持微型激光焊枪悬停在义肢手腕处，细微的蓝色电弧光微微映亮面庞，神情极度专注严肃。

【空间、机位与构图】
- 画幅与景别：16:9 宽银幕横构图，腰部以上中景（Medium Shot），医生位于画面右侧三分之一处，左侧为手术台延伸与散落的精密零件。
- 摄影机镜头：35mm 电影镜头，大光圈中浅景深，焦点精准锁在医生面部与焊接电弧上，背景纵深处的全息陈列柜柔和虚焦。

【光影系统与色彩氛围】
- 光影设计：典型高反差 chiaroscuro 光影。主光源为焊接产生的锐利冷蓝电弧点光源，从斜下方打亮下颌与鼻梁；头顶上方是一盏昏黄旧式手术吊灯，形成冷暖交织的强烈戏剧张力。
- 色彩基调：冷灰暗青与暗黄主导，明暗交界清晰，暗部层次丰富。

【绝对排除项】
严禁生成字幕、文字标签、水印、手部多指/缺指畸变、过度磨皮塑料质感。
```

### 范例 2：微创局部编辑任务卡 (EDIT)

```markdown
## 图像任务：CHAR_001_BATTLE_DAMAGE_EDIT

- model: gpt-image-2.5
- task_type: EDIT
- purpose: 角色战损轻伤状态微创微调
- quality: high
- size: 1792x1024
- background: opaque
- output_format: png

### 输入主基准图
1. path_or_status: `[本地路径]/角色A_胸上特写基准.png`
   - priority: 1（绝对基底）
   - role: PRIMARY_BASE_IMAGE

### 结构化编辑指令 (Structured Edit Prompt)

【唯一修改项 (CHANGE)】
只将参考基准图中主角的右侧额角至眉骨上方位置，添加一条长约2.5厘米的轻微新鲜擦伤划痕：表面带有渗血微红血痂，伤口边缘皮肤轻度泛红，皮下组织层次细腻逼真。

【绝对保持项 (PRESERVE EXACTLY)】
除上述唯一点状修改外，基准图中的以下所有属性必须像素级绝对保持：
1. 人物面部五官轮廓、眼睛注视方向、眼眸光斑、唇色及冷峻表情完全不变；
2. 头发长度、发型分缝与零散发丝受光完全不变；
3. 身穿的外套款式、拉链褶皱、布料光影与纽扣细节完全不变；
4. 摄影机镜头焦段、胸部以上景别构图、景深范围完全不变；
5. 画面主光源方向、冷调暗蓝氛围与背景所有陈设完全不变。

【绝对排除 (EXCLUDE)】
严禁改变未指定的面部其他区域，严禁额外平滑磨皮，严禁改变背景物体与光照。
```
